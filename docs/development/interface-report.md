# Evaluation, explanation and dashboard delivery

Owned files: `src/fabfederate/evaluation/`, `src/fabfederate/explain/`, `app/streamlit_app.py`, `tests/test_evaluation.py`, `tests/test_explain.py`, `tests/test_dashboard.py`.

## Exports and integration

- `evaluation.metrics.regression_metrics(y_true, y_pred)` returns MAE, pooled RMSE, median absolute error and R² (`None` for singleton/constant targets). Rejects empty, unequal, nonfinite and non-vector inputs.
- `evaluation.metrics.evaluate_predictions(frame)` consumes one dataset/method/seed/scenario/split and returns `pooled`, macro `group_mae`, `worst_client_mae`, `by_group`, `by_client`, `client_summary_available`, `client_covered_windows`, `count`, `windows`, `groups`. Units must be consistent; every window requires an independent group. Missing held-out client IDs yield an empty client table and `None`, never invented domains.
- `evaluation.report.generate_report(experiment_dir)` produces `report.md`, `evaluation_summary.csv`, auditable plotted `overview_predictions.csv`, full `group_errors.csv`, optional `cost_by_run.csv`, and bounded publication-size PNG figures in `figures/`. Inputs are only `metrics.csv`, `predictions.csv`, `rounds.csv`; no scores are hand-entered. Test summary spans recorded scenarios/seeds. Overview figures use IID test where present, otherwise a recorded stratum explicitly identified. Repeated-window predictions average across seeds descriptively; case bars average seed-level MAEs, max40 bars. Largest10 recorded window errors identify failure cases. Tables capped60 rows link full CSVs. Convergence means/std and cost totals/seed means are labelled. Matplotlib loads lazily, so model/test imports do not invoke macOS font discovery.
- `explain.shap_analysis.explain_prediction(bundle, background, samples, max_background=32, max_evals=None)` explains the exact selected bundle's raw-feature `predict` including saved transform. Deterministic permutation SHAP uses seed42, evenly spaced at-most32 training reference rows, default three forward/reverse permutations. Result includes ordered names, values, base predictions, selected-model predictions, reconstruction error/tolerance, runtime, background indices/hash, SHAP version, model kind and units. Invalid schema/order, nonfinite features, insufficient budgets, predictor shape/finite errors and failed reconstruction raise clearly. Caller must provide training-only background. Same API handles actual RF and PyTorch model; no surrogate is substituted.
- `save_explanation(result, path)` writes strict JSON; `top_k_agreement(a,b,k)` compares absolute-magnitude indices using deterministic ties; `sign_agreement(a,b)` includes zero-zero sign matches.

## Dashboard

Launch `.venv/bin/streamlit run app/streamlit_app.py`. Default experiment root is repository `experiments/`; `FABFEDERATE_EXPERIMENTS_DIR` overrides for isolated testing. Each directory can contain `features.parquet`, `audit.json`, `manifest.json`, `metrics.csv`, `predictions.csv`, `rounds.csv`, and selected bundles `models/<method>/bundle.joblib` plus manifest/card. Models load with `load_bundle(models/<method>/)`.

Five native Streamlit screens: Data Explorer, Experiment Comparison, Client Heterogeneity, Convergence / Cost, Wear Estimate. Navy/teal research styling, labelled controls, useful missing-artifact states, real values only. Source and physical-tool limits, unavailable campus evidence, no formal privacy guarantee, noncausal SHAP, no calibrated uncertainty and human review are explicit.

Wear Estimate selects actual held-out feature records or uploaded ordered raw-feature CSV. Uploads require exact selected schema/order, UTF-8, finite numeric rows, max10MiB/1000rows; duplicate/missing/reordered/extra columns and labels are rejected. Optional measured wear is separate and never reaches the predictor. Prediction uses saved transformation. Explanation uses cached exact selected bundle plus only feature-table `split == train` background; explanation JSON is downloadable with settings. Model provenance and units are shown. No machine commands or unvalidated numerical inspection thresholds exist.

## Limits

SHAP references require finite complete rows; unavailable backgrounds or invalid samples fail visibly. Stability helpers are implemented; empirical cross-seed/case stability study orchestration and experiment evidence belong to root. Explanations are bounded approximations; additivity is checked but does not establish causal interpretation. Report charts summarize recorded experiments without independence/confidence claims. NASA case-heldout evaluation is not verified cross-physical-tool validation. Campus validation remains unavailable.

Official docs consulted: [SHAP PermutationExplainer](https://shap.readthedocs.io/en/latest/generated/shap.PermutationExplainer.html), [Streamlit AppTest](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest). Applied frontend-ui-engineering and browser-testing-with-devtools skill guidance; root performs live-browser checks.

## Review correction: source-cut identity

Report overview predictions preserve every recorded sample/method provenance column, including dataset_id/run_id/group_id/window_id/wear_target; only seed is averaged. Distinct cuts whose per-cut window number and measured target coincide stay separate. `overview_predictions.csv` records each plotted point and its contributing `recorded_seeds` count. Duplicate identical provenance within one seed fails clearly. Regression coverage uses two source cuts with identical case/window/target and two seeds; their separate means must remain0.2 and0.7. Read-only check on nasa-smoke FedAvg:161 source identities yield161 overview points (previous implementation merged to157). No saved experiment artifacts were changed by this correction.
